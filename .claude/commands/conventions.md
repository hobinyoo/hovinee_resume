description: 팀 프론트엔드 컨벤션 요약을 출력한다.
---

루트 `CONVENTIONS.md`를 읽고, 아래 항목을 간결한 표/불릿으로 요약해 사용자에게 보여줘:

1. 네이밍 규칙 (파일/폴더/컴포넌트/훅/타입/상수) + TanStack Router 특수 파일 예외
2. 디렉토리 구조 (기능 기반 + 콜로케이션, `routes/`는 라우팅 전용)
3. 컴포넌트 파일 구조 (평탄 기본 → 동반파일 시 승격, index 배럴 금지)
4. 서버 상태 (query key factory + queryOptions)
5. 커밋 타입 고정 세트 + 브랜치 규칙(`feat/…`)

만약 사용자가 특정 항목만 물었다면 해당 부분만 답한다. 규칙의 근거가 필요하면 `CONVENTIONS.md`의 해당 절을 인용한다.
